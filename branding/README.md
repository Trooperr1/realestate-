# Cofimo — Luxury Real Estate Brand Identity

A complete black-and-white brand identity for Cofimo.

## Contents

- **`brand-guidelines.html`** — the full brand book: positioning, logo system, clear space
  and misuse rules, color palette, typography, voice & tone, and application previews. Open
  it directly in a browser.
- **`logo/`** — logo files
  - `cofimo-wordmark-black.svg` — primary wordmark, for light backgrounds
  - `cofimo-wordmark-white.svg` — reverse wordmark, for dark backgrounds
  - `cofimo-monogram-black.svg` — monogram mark, for light backgrounds (avatars, favicons)
  - `cofimo-monogram-white.svg` — monogram mark, for dark backgrounds
- **`social-media/`** — ready-to-use post templates (edit the placeholder text in any SVG or
  vector editor before publishing)
  - `instagram-post-new-listing.svg` — 1080×1080, property listing post
  - `instagram-post-quote.svg` — 1080×1080, brand quote / tagline post
  - `instagram-post-brand-launch.svg` — 1080×1080, launch / announcement post
  - `instagram-story.svg` — 1080×1920, story template
  - `facebook-cover.svg` — 820×312, page cover banner

## System at a glance

- **Colors**: Cofimo Black `#0A0A0A`, Cofimo White `#FFFFFF`, Ivory `#FAFAF8` (background only),
  Graphite `#4A473F` (secondary text only). No third color is used anywhere in the system.
- **Type**: serif (Georgia / Times New Roman fallback stack) for the wordmark and headlines,
  set at wide tracking; a clean sans-serif for body copy and small-caps eyebrow labels.
- **Mark**: a single diamond accent doubles as a divider under the wordmark and as a flourish
  on the monogram — the only recurring graphic device in the system.

All SVGs are plain text/vector files — open them in a browser, Figma, Illustrator, or Inkscape
to view, edit, or export to PNG/JPEG at any resolution.
